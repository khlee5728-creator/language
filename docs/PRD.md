# PRD — 강의 자료 제작 프로젝트

> **Product Requirements Document**
> 이 문서는 *영어학 특강* 프로젝트에서 정립한 강의 자료 제작 방침을 정리한 것으로,
> **향후 다른 교재·과목 프로젝트를 시작할 때 기준 문서(template)** 로 사용한다.
> 프로젝트가 진행됨에 따라 주요 변경 사항을 이 문서에 계속 반영·업데이트한다.

- **문서 버전**: 1.0
- **최초 작성**: 2026-07-03
- **최종 수정**: 2026-07-03
- **적용 사례**: 영어학 특강 (Topics in English Linguistics), 2026학년도 2학기

## 1. 제품 개요 (Overview)

대학 강의를 운영하기 위한 **주차별 HTML 슬라이드 + 강의 허브(index)** 세트를 제작한다.
학생 대면 강의와 자기 주도 복습에 모두 사용할 수 있는, 저장소 자체로 완결되는(self-contained)
웹 기반 강의 자료를 목표로 한다.

- **산출물**: 강의 허브 `index.html` + 주차별 슬라이드 `slides/weekNN.html` + 강의계획서
- **배포**: GitHub Pages (공개) — 저작권에 유의해야 하는 근본 이유
- **뷰어**: 최신 브라우저, 별도 빌드/설치 없이 파일 열기만으로 재생

## 2. 목표 & 배경 (Goals & Why)

| 목표 | 설명 |
|------|------|
| 대면 강의 자료 | 15주 강의를 운영할 수 있는 슬라이드 |
| 학습 목표 정합성 | 교재 기반 개념을 정확히 전달, 원문 용어에 노출 |
| 재사용성 | 디자인 시스템·자산을 다른 과목에서도 재활용 |
| 완결성 | 외부 폴더 의존 없이 저장소만으로 동작 |

## 3. 대상 사용자 (Users)

- **1차 사용자**: 강의자(교수) — 강의 진행 및 발표자 노트 활용
- **2차 사용자**: 수강생 — 예습·복습, 인터랙티브 퀴즈로 자기 점검

## 4. 핵심 요구사항 (Requirements)

### 4.1 콘텐츠 언어 정책 (중요)
- **기본 언어는 영어**. 제목·본문·정의·예시·핵심 용어는 영어로 작성한다.
- 한국어는 필요할 때만 **부연 설명**으로 덧붙인다. `.ko-supp` 클래스로 감싼다.
- **한국어 On/Off 토글** 제공 — 학생 수준에 맞춰 한국어 노출을 조정(localStorage 기억).
- 발표자 노트(`<aside class="notes">`)는 한국어 유지(무대 밖 설명이므로 토글 대상 아님).
- *근거*: 영어영문학·영어학 과목 — 학생이 영어 원문 용어·설명에 노출되는 것이 학습 목표에 부합.

### 4.2 저작권 정책 (중요 — 공개 배포이므로 필수)
- **교재 Exercise 원문 복제 금지** → 개념 중심 **오리지널 MCQ**로 재구성하고 "교재 p.X Ex.N" 참조만 표기.
- **교재 도표·이미지 스캔 삽입 금지** → **SVG/CSS로 자체 재현**하거나 CC 라이선스 이미지 사용.
- 인용은 최소한의 예문·용어에 한정하고 출처(교재·판·페이지)를 명기.

### 4.3 슬라이드 구성 패턴 (표준 흐름)
```
Title → Agenda → 본문(개념) → (도표/SVG) → Practice MCQ
      → Exercises(교재 기반 재구성 MCQ) → Summary → Next Week
```
- 각 슬라이드에 한국어 발표자 노트 포함.
- 주차별 accent color를 지정해 시각적 구분.

### 4.4 인터랙티브 요소
- **객관식 퀴즈(MCQ)**: 선택 시 정답/오답 표시 + 해설 노출. 자기 점검용.
- **PDF 내보내기 버튼**: 인쇄용 저장.
- **한국어 On/Off 버튼**: 우상단 주입.

### 4.5 강의 허브 (index.html)
- 15주 카드형 레이아웃. 완료된 주차는 클릭 가능한 링크 + "✓ 슬라이드 완료" 배지.
- 챕터별 accent color로 과목 구조를 시각화.

## 5. 범위 (Scope)

### In Scope
- 주차별 강의 슬라이드(HTML), 강의 허브, 강의계획서(HTML)
- 인터랙티브 퀴즈, PDF 내보내기, 한국어 토글
- 교재 기반 개념의 오리지널 재구성

### Out of Scope
- 교재 원문·도표의 그대로 복제
- 시험 문제 자료의 공개 저장소 푸시 (**절대 금지** — TRD 참고)
- LMS 연동, 자동 채점 서버

## 6. 제약 & 원칙 (Constraints)

- **공개 저장소** 전제 → 저작권 안전이 최우선 제약.
- **시험/평가 자료는 원격 저장소에 푸시하지 않는다.**
- **git push는 사용자가 명시적으로 요청할 때만** 수행한다.
- 슬라이드는 외부 폴더 의존 없이 저장소 내에서 완결.

## 7. 성공 지표 (Success Criteria)

- 각 주차 슬라이드가 브라우저에서 오류 없이 재생되고 PDF로 저장된다.
- 영어 기본 + 한국어 토글이 정상 동작한다.
- 교재 원문·도표 복제 없이 개념이 정확히 전달된다.
- 다른 과목 프로젝트가 이 문서 + TRD만으로 동일 품질을 재현할 수 있다.

**영어학 특강** — 2026학년도 2학기, 15주
- 교재: Fromkin, Rodman & Hyams, *An Introduction to Language*, 11th Ed. (Ch.1–6)
