The Function of Phonological Rules

Rules derive phonetic forms from phonemic representations
/phonemic/ — rules → [phonetic]
  • The mental form /p/ becomes [pʰ] word-initially by an aspiration rule.
  • Rules are general: they apply to whole natural classes, not single sounds.

※ 음운 규칙 = 음소 표상 → 음성 표상으로 가는 함수. 화자가 저장하는 것은 음소, 실제로 말하는 것은 이음.

음운 규칙은 화자의 머릿속 음소 표상을 실제 발음으로 변환합니다. 규칙이 개별 소리가 아니라 자연 부류(예: 모든 무성 파열음)에 작동한다는 일반성이 핵심입니다.

Types of Phonological Rules

Assimilation
a sound becomes more like a neighbor — vowel nasalization before [n]
Dissimilation
a sound becomes less like a neighbor to ease articulation
Insertion (epenthesis)
a segment is added — the [ə] in buses
Deletion
a segment is dropped — silent g in sign

These match the book's four rule functions: change feature values, add features, delete segments, add segments. (cf. textbook Ch.6, p.241)

※ 동화(assimilation)가 가장 흔하다 — 조음의 경제성 때문에 이웃 소리를 닮아간다.

네 규칙 유형을 소개합니다. 동화가 가장 흔하며, 대부분 조음 경제성(ease of articulation)에서 비롯됩니다. 각 유형의 영어 예시를 하나씩 제시해 체감시키세요. (전위(metathesis)는 이 장의 규칙 기능 목록에 없어 제외했습니다.)

Rule Formalism · A → B / C __ D

Read: "A becomes B in the environment between C and D." The bar __ marks the target's position.

V → [+nasal] / __ [+nasal] $

A vowel becomes nasalized before a nasal consonant in the same syllable. The $ marks a syllable boundary — it keeps the rule from crossing over, so denote /dɪ$noʊt/ is not nasalized. (cf. textbook Ch.6, p.236)

※ 화살표 왼쪽=바뀌는 대상, 오른쪽=결과, 빗금 뒤=환경, 밑줄=대상이 놓이는 자리, $=음절 경계(같은 음절 안에서만 적용).

규칙 표기법의 네 요소(대상·결과·환경·밑줄 위치)를 또박또박 읽어주세요. 12주차 비음화를 이 형식으로 다시 쓰면 규칙이 어떻게 이음을 도출하는지 한눈에 보입니다.

Diagram · Syllable Structure

A syllable (σ) divides into an Onset and a Rime; the Rime holds the Nucleus and Coda.

※ 핵(nucleus, 보통 모음)만 필수 — 두음(onset)과 말음(coda)은 언어·단어에 따라 선택적이다.

음절 나무: σ → Onset + Rime, Rime → Nucleus + Coda. 핵만 필수이고 두음·말음은 선택적입니다. cat=[kæt]을 나무에 대응시켜 각 자리를 확인시키세요. 이 구조가 다음 강세·음소배열 논의의 토대입니다.

Stress & Rule Interaction

  • Word stress — one syllable is prominent: phoTOGraphy vs. PHOtograph.
  • Phrase & sentence stress — a GREENhouse (compound) vs. a green HOUSE (phrase).
  • Rule interaction ("pull rank") — rules apply in order; one rule can feed or bleed another.

Stress placement itself is rule-governed and shifts as words take affixes.

※ 강세는 자유롭지 않고 규칙 지배적 — 접사가 붙으면 강세 위치가 규칙적으로 이동한다(phótograph→photógraphy).

강세도 규칙의 지배를 받습니다. 접사 첨가로 강세가 이동하는 예(photograph→photography)와 복합어/구의 강세 대비(GREENhouse vs. green HOUSE)를 활용하세요. 규칙 순서(rule ordering)도 소개.

Sequential Constraints (Phonotactics)

Rules on which sound sequences are possible in a language
  • ✓ blick [blɪk] — a possible (accidental gap) English word
  • ✗ *bnick [bnɪk] — impossible: English bans word-initial /bn-/
  • ✗ *ngick [ŋɪk] — English /ŋ/ cannot begin a word

Speakers judge *bnick impossible without ever being taught — phonotactic knowledge is part of the grammar.

※ 음소배열 제약은 '가능한 단어'와 '불가능한 단어'를 가른다 — 배운 적 없어도 직관으로 안다.

음소배열론(phonotactics)은 소리의 배열 제약입니다. blick(가능하나 우연히 비어있음)과 *bnick(불가능)의 대비가 다음 슬라이드의 어휘 공백 구분으로 이어집니다.

Lexical Gaps — Accidental vs. Systematic

Accidental Gap

blick obeys English phonotactics but happens not to be a word. It could become one.

Systematic Gap

*bnick violates a phonotactic rule, so it can never be an English word.

The gap between them shows speakers know the rules, not just the existing words.

※ 우연한 공백은 규칙을 지키나 비어있을 뿐, 체계적 공백은 규칙 자체가 막는다.

우연적 공백(accidental gap)과 체계적 공백(systematic gap)의 구분이 핵심입니다. 전자는 규칙을 지키지만 우연히 비어있고, 후자는 규칙이 원천 봉쇄합니다. 이 구분이 화자의 규칙 지식을 증명합니다.

Phonological Analysis — Deriving Rules from Data

Given a set of forms, we infer the rule that predicts the alternation.

  1. List the sounds in question and their environments.
  2. Check for minimal pairs (contrast) vs. complementary distribution (allophones).
  3. State the rule in A → B / C __ D form, using the smallest natural class.

Worked example — the alveolar flap: writer and rider both surface with [ɾ]. Since [ɾ] appears only between a stressed and an unstressed vowel, the rule is /t/, /d/ → [ɾ] / V́ __ V. (cf. textbook Ch.6, pp.251–252)

※ 자료 → 환경 정리 → 대립/상보 판별 → 규칙 진술. 가장 단순·일반적인 규칙이 최선.

음운 분석의 절차를 단계로 제시합니다. 상보적 분포가 확인되면 어느 이음이 '기저형(phoneme)'인지 정하고, 나머지를 규칙으로 도출합니다. 간결성·일반성이 좋은 분석의 기준임을 강조하세요.
Practice · Check Your Understanding
1A vowel becoming nasalized before a nasal consonant is an example of which rule type?
Explanation The vowel takes on the [+nasal] feature of the following consonant, becoming more like its neighbor — the definition of assimilation. Dissimilation makes a sound less like its neighbor; deletion removes segments.
동화의 정의(이웃 소리를 닮음)를 확인합니다. 오답들(전위·삭제)과의 대비로 개념을 선명히 하세요.
Practice · Check Your Understanding
2In the syllable tree, which node is obligatory in every syllable?
Explanation The nucleus (usually a vowel) is the only obligatory part of a syllable. Onsets and codas are optional and vary by language and word.
음절의 필수 요소는 핵(nucleus)뿐임을 확인합니다. 두음·말음은 선택적이라는 점을 나무 그림과 연결하세요.
Exercises · Based on Textbook Ch.6
3Which nonsense word is an *impossible English word (a systematic gap)? (cf. textbook Ch.6, pp.217, 249)
Explanation English phonotactics forbid the initial cluster /bn-/, so bnick is a systematic gap that can never be a word. blick and strick obey English rules and are merely accidental gaps.
체계적 공백 판별 문항(재구성). /bn-/ 어두 자음군이 영어에서 금지된다는 제약을 확인시키세요.
Exercises · Based on Textbook Ch.6
4The rule V → [+nasal] / __ [+nasal] $ should be read as: (cf. textbook Ch.6, p.236)
Explanation The target (left of →) is a vowel; the change is [+nasal]; the environment places the vowel before a [+nasal] segment marked by the bar __. The $ is a syllable boundary, so nasalization applies only within one syllable (bean), not across it (denote).

Summary

Key Points

  • Phonological rules derive phonetic forms from phonemic ones
  • Types: assimilation, dissimilation, insertion, deletion (four rule functions)
  • Rules are written A → B / C __ D and target natural classes
  • The syllable = Onset + Rime (Nucleus + Coda); only the nucleus is obligatory
  • Stress is rule-governed; rules can interact and be ordered
  • Phonotactics separate accidental gaps (blick) from systematic gaps (*bnick)
